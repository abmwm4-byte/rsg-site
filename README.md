# RSG Group — сайт автосервиса

Сайт автосервиса по ремонту стартеров и генераторов (Минск).
Стек: Astro + Tailwind CSS → статический HTML. Хостинг: Cloudflare Pages (бесплатно).

## Команды

```bash
npm install      # установить зависимости
npm run dev      # запустить локально: http://localhost:4321
npm run build    # собрать сайт в папку dist/
```

## Как внести правки (тексты, цены, телефоны)

Почти весь контент — в одном файле: **`src/data/site.ts`**
(телефоны, мессенджеры, услуги, цены калькулятора, вопросы-ответы).

Тексты страниц — в `src/pages/*.astro`.

Простой способ без установки чего-либо:
1. Открыть файл на GitHub → кнопка с карандашом (Edit).
2. Изменить текст → Commit changes.
3. Сайт обновится автоматически за ~1 минуту.

## Структура

- `src/data/site.ts` — все данные и контент
- `src/pages/` — страницы (главная, услуги, регионы, контакты)
- `src/components/` — блоки (шапка, футер, калькулятор, галерея)
- `src/layouts/` — общий каркас страниц
- `public/images/` — фото
- `public/robots.txt` — правила для поисковиков
