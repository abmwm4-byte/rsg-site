# Задание для владельца «RSG Group» — что нужно для запуска сайта

Здравствуйте! Новый сайт почти готов. От вас нужно 4 вещи — суммарно примерно час времени.

## 1. Прайс (самое важное)

Пришлите списком по образцу — для стартеров и генераторов отдельно:

```
Работа | Цена от–до | Срок
Диагностика на стенде | 20–30 BYN | 20–30 мин
Замена щёток | ..–.. BYN | ...
Замена бендикса | ...
Замена втягивающего реле | ...
Замена подшипников (генератор) | ...
Диодный мост | ...
Регулятор напряжения | ...
Полная переборка | ...
Снятие/установка узла на авто | ...
```

- Реальные вилки — клиент не должен удивиться цене на месте
- Подтвердите: гарантия 3 месяца на работы и запчасти — верно?
- Диагностика при последующем ремонте у вас — бесплатная или как?

## 2. Telegram (2 минуты)

Кнопка Telegram на сайте ведёт на чат по номеру. Чтобы она работала у всех:
**Настройки → Конфиденциальность → Номер телефона → «Кто может найти меня по номеру» → «Все»**.

Дополнительно (по желанию, но красивее): **Настройки → Изменить → Имя пользователя** →
придумайте username (например, `rsg_group`). Тогда ссылка будет короче и с именем.
Пришлите, что получилось.

## 3. Фото мастерской (30 минут, телефон)

Снимите горизонтально, при дневном свете, без номеров авто и лиц клиентов:
- [ ] Фасад/вход (чтобы клиенты узнавали место)
- [ ] Бокс и верстак
- [ ] Стенд проверки стартеров/генераторов
- [ ] Склад запчастей
- [ ] Процесс: разобранный стартер и генератор «до» ремонта (2–3 шт.)
- [ ] Вы сами у стенда или в боксе (1–2 фото — сильно повышает доверие)

## 4. Кейсы (1–2 в неделю, 5 минут)

По каждому ремонту присылайте в мессенджер:
1. Авто (марка/модель, год)
2. Узел: стартер/генератор
3. Симптом словами клиента
4. Что оказалось при разборке
5. Что сделали (работы, запчасти)
6. Срок и итоговая цена
7. Фото «до» обязательно, «после» — по возможности

Подробное ТЗ с примером: `docs/cases-brief.md` в репозитории.
Первые 2 кейса нужны до запуска — сейчас на сайте стоят шаблонные заглушки, их надо заменить.

## 5. Доступы (восстановим через вашу почту Gmail)

- Панель регистратора домена remontstarterov.by (active.by или hoster.by) — попробуем восстановить по почте, может понадобиться ваш код из письма
- Права владельца в **Яндекс Бизнесе** (карточка с отзывами — там сейчас чужие услуги: амортизаторы и двигатели, это надо почистить)
- Права в **Google Business Profile** (карточка в Google Maps)
