# Google Ads для RSG Group — пошаговая настройка кабинета

**Аккаунт:** servis.rsggroup@gmail.com · **Бюджет:** $300/мес (~$10/день) · **Ведёт:** владелец сам
**Время сборки по этой инструкции:** 30–40 минут

> Без GA4 пока обходимся встроенной отчётностью Google о звонках (часть 2).
> GA4 и импорт конверсий — отдельный шаг позже (часть 10).

---

## Часть 0. Что подготовить

- Gmail servis.rsggroup@gmail.com
- Банковская карта (Visa/Mastercard, включённые интернет-платежи)
- Телефон под рукой

## Часть 1. Создание кабинета (5 минут)

1. Зайти на **ads.google.com** под servis.rsggroup@gmail.com → «Начать».
2. Google предложит умную кампанию — **пропустить**: внизу ссылка «Перейти в экспертный режим» (Switch to Expert Mode). Без неё контроль урезан.
3. Выбрать **«Создать аккаунт без кампании»**.
4. Страна биллинга: Беларусь. Часовой пояс: **(GMT+03:00) Минск** — необратимо.
5. Валюта: USD или BYN (что предложит) — необратимо, меняется только созданием нового аккаунта.
6. В биллинге указать данные плательщика. Если платит ИП/юрлицо — ввести УНП 193151171 (влияет на НДС в счетах).

## Часть 2. Отчётность о звонках (без счётчиков)

Это единственная конверсия, которая работает без GA4 — включаем сразу:

1. **Настройки аккаунта → Отчётность о звонках → Включить.**
2. Расширение «Звонок» (часть 7) будет считать звонки с объявлений автоматически.
3. Звонки с сайта без GA4/Google Tag считать нельзя — поэтому GA4 всё равно нужен (часть 10). Пока ориентируемся на звонки с объявлений + общий объём звонков по факту.

## Часть 3. Кампания

**Инструменты → Кампании → Создать → Цель: «Создать кампанию без рекомендаций» → Тип: «Поиск»**

Настройки (вводить точно):

| Параметр | Значение |
|---|---|
| Сети | Только **Поиск Google**. СНЯТЬ галки «Поисковые партнёры» и «Контекстно-медийная сеть» |
| Гео | Минск + радиус **30 км** |
| Вариант гео-таргетинга | **«Присутствие»** (НЕ «присутствие или интерес» — иначе показы всему миру, кто гуглит про Минск) |
| Язык | Русский |
| Бюджет | **$10 в день** |
| Ставки | **Максимальное количество кликов** + ограничение цены за клик **$1.50** |
| Расписание | Пн–Вс **09:00–19:00** (когда берут трубку) |
| Автоматическая пометка (auto-tagging) | Включить (Настройки аккаунта → Настройки → Автопометка) |

## Часть 9. Еженедельная рутина владельца (10 минут, по воскресеньям)

1. **Расход** — должно уходить ~$70/неделю.
2. **Поисковые запросы** (Ключевые слова → Поисковые запросы): всё нецелевое — в минус-слова. Примеры нецелевого: схемы, «как сделать самому», марки железа, вакансии.
3. **Звонки** — сколько было и сколько стоил каждый (расход ÷ звонки). Норма для старта: ≤ $15.
4. CTR ниже 5% по группе — переписывать заголовки (со мной).
5. Первые 2 недели — НЕ менять ставки и бюджет: идёт обучение.

## Часть 10. Следующий шаг: GA4 (когда будем готовы)

1. Создать GA4 (analytics.google.com, тот же Gmail) + Яндекс Метрику → прислать мне ID — вставлю в сайт за 5 минут.
2. Цели `call`, `telegram`, `whatsapp`, `viber`, `route` уже размечены в коде.
3. В Google Ads: Инструменты → Конверсии → Импорт из GA4 (ключевые события).
4. После 2–3 недель данных: ставки «Максимум конверсий» вместо «Максимум кликов» — качество трафика заметно вырастет.
