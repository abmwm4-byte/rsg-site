# Перенастройка Google Ads RSG Group — диагноз и план действий

**Анализ от 02.08.2026** (скриншоты + 6 CSV-отчётов за всё время, период работы с 10 июля)

## Что сейчас (факты)

- 2 кампании, обе «Поиск», «Максимум кликов», бюджет $4.72 + $4.00/день (~$262/мес)
- **Гео: только Фрунзенский район** — не весь Минск
- Все 45 ключевых слов — **широкое соответствие**
- Стартеры: 212 показов, почти все ключи по 0 кликов · Генераторы: 5 138 показов, CTR 6.25%
- Генераторы: статус «Ограничено бюджетом» — теряем показы
- **54% расхода** ($57.69 из $106.98) скрыто в «Другие поисковые запросы» — не проверить
- Минус-слова (41) есть только у генераторов; у стартеров — ноль
- Конверсии: **0.00** (объяснение ниже, п.4)
- Объект «Звонок»: номер в формате `8 029 153-92-22`; доп.ссылка со склеенным текстом `Ремонт стартеровhttps://...`
- Расписание 8:45–18:45 при рабочем дне до 19:00; язык «Английский» лишний

## Диагноз (4 главные болезни)

1. **Гео убито.** Сервис обслуживает весь Минск, а показы идут на один район. Это главная причина малых объёмов.
2. **Кампания стартеров мертва.** Широкое соответствие + «обучение» → Google отдаёт показы кампании генераторов (стартерные запросы обслуживает она же, с объявлениями про генераторы).
3. **Перекрёстное сопоставление.** Нет кросс-минусов: генераторные ключи ловят стартерные запросы и наоборот.
4. **Конверсии не считаются — и не будут без GA4.** Номеров переадресации Google (call tracking) **в Беларуси нет**, поэтому звонки с объявлений Google не считает. Цель «привлечённый по телефону» висит активная с нулём. Выход: конверсии сайта через GA4 (цели `call/telegram/whatsapp/viber/route` уже размечены в коде) → импорт в Google Ads.

## План действий (по шагам, 30–40 минут)

### Шаг 1. Гео — главная правка (обе кампании)

Кампания → Настройки → Местоположения:
- Удалить «Frunzyenski District»
- Добавить **Минск** + **радиус 30 км** вокруг Минска
- Вариант таргетинга: **«Присутствие»** (не «присутствие или интерес»)

### Шаг 2. Расписание и язык (обе кампании)

- Расписание: **09:00–19:00, все дни**
- Языки: оставить только **Русский** (убрать Английский)

### Шаг 3. Реанимация стартеров

Кампания «RSG group - Ремонт стартеров»:
1. Добавить ключи из `docs/google-ads-setup.md` (часть 4, группа 1) — **фразовое `"..."` и точное `[...]`** соответствие
2. Добавить **весь список минус-слов** из той же инструкции (часть 5)
3. Бюджет: поднять до **$5/день** (генераторам тоже $5 — итого $10/день = $300/мес)

### Шаг 4. Кросс-минуса (против перекрёстного сопоставления)

- В кампанию **генераторов** добавить минус-слова: `стартер`, `стартера`, `стартеров`, `бендикс`, `втягивающее`
- В кампанию **стартеров** добавить минус-слова: `генератор`, `генератора`, `генераторов`, `диодный мост`, `подшипники генератора`

### Шаг 5. Ревизия минус-слов генераторов

- **Удалить:** `неисправности` (это как раз клиенты с симптомами!), `гродно` (принимаем Европочтой со всей РБ)
- **Оставить и дополнить** списком из инструкции (часть 5): бензогенератор, электростанция, генератор для дома, выезд, ночью, круглосуточно, 24 часа — всё верно

### Шаг 6. Объекты (расширения)

- **Звонок:** исправить номер на **+375 29 153-92-22** (с плюсом и кодом страны)
- **Доп.ссылки:** исправить склеенную `Ремонт стартеровhttps://...` (текст отдельно, URL отдельно); добавить: Ремонт генераторов, Диагностика, Для регионов, Контакты
- **Уточнения:** заменить на: Гарантия 3 месяца · Свой склад запчастей · Осмотр в день обращения · Без выходных · Доставка по РБ за наш счёт
- **Структурированные описания:** Услуги → Ремонт стартеров, Ремонт генераторов, Диагностика, Переборка, Замена бендикса, Замена щёток
- «Все марки авто» из уточнений убрать (грузовые не делаем, лишнее)

### Шаг 7. Объявления

- В каждую группу добавить RSA-объявление из инструкции (часть 6) — старые объявления не трогать, Google сам выберет лучшее ротацией
- URL старого объявления стартеров проверить: должен вести на `/remont-starterov/` (новый сайт), не на Tilda

### Шаг 8. Конверсии (корень нулей)

1. Создать GA4 + Яндекс Метрику (10 минут) → прислать мне ID — вставлю в сайт
2. В Google Ads: Инструменты → Конверсии → Импорт из GA4 → события `call`, `whatsapp`, `telegram`, `viber`, `route`
3. Пока GA4 нет — ориентируемся на фактические звонки (владелец считает сам)
4. Ставку «Максимум кликов» оставить до накопления 15–20 конверсий, потом «Максимум конверсий»

### Чего НЕ делать

- Не кликать по своим объявлениям
- Не менять ставки/бюджет первые 2 недели после правок (переобучение)
- Не включать «Поисковых партнёров» и КМС

## Контроль через 2 недели (чек-лист)

- [ ] Показы стартеров выросли с 212 до уровня генераторов
- [ ] «Ограничено бюджетом» исчезло или смягчилось
- [ ] CTR стартеров ≥ 5%
- [ ] Звонки: фактическое число vs прошлый месяц
- [ ] «Другие поисковые запросы» по расходу < 40% (сузится с фразовым/точным)
