- **Тёмная тема:** класс `.dark` на `<html>`, переключатель в шапке, режим «Авто» считает восход/заказ Минска солнечной формулой в `src/layouts/Base.astro`

## 6. Конвейер фото (обязательный, были ловушки)

1. Скопировать в `public/images/` (HEIC → сначала через sips в JPEG)
2. Поворот пикселей если нужен (`sips -r`), **потом срезать EXIF** (был баг двойного поворота: айфон пишет orientation=6)
3. Блюр номеров: Pillow — мозаичный блюр, координаты по пропорциям, проверять глазами
4. **Конвертация в WebP**: `sharp(src).webp({quality:82})` → `имя.webp`, исходный jpg удалить
5. Имена — смысловые (`audi-a3-1.webp`), alt — осмысленный. Превью `-thumb.webp` создаст `scripts/make-thumbs.mjs` при билде сам
6. Исключение: `workshop-engine.jpg` остаётся JPEG — это og:image (мессенджеры плохо переваривают WebP в превью ссылок)

## 11. Ловушки (не наступать повторно)

- **EXIF orientation=6** у айфоновских фото: срезать EXIF ПОСЛЕ поворота пикселей (sips -r), иначе двойной поворот в браузере
- **Не логиниться чужими паролями** — доступ к Google Ads/Яндексу через приглашения пользователей
- **AdsApp недоступен в standalone Apps Script** для этого аккаунта — статистика идёт через Sheet-мост (писатель в Google Ads Scripts)
- **Viber нельзя скрывать на десктопе** — в Беларуси он основной мессенджер (была ошибка, откачена)
- **t.me/+375...** — рабочий формат чата по номеру (не t.me/username только)
- IDE-превью и git иногда расходились — после правок проверять `git diff`
