# ТЗ: Кейсы для сайта (для мастера)

## Зачем

Кейсы — это короткие истории реальных ремонтов на сайте. Они:
- выводят сайт в поиске по запросам вида «ремонт стартера пассат», «генератор не заряжает mazda»;
- доказывают опыт лучше любой рекламы;
- дают живые фото вместо стоковых.

**Ритм: 1–2 кейса в неделю.** Один кейс = 5 минут вашего времени.

## Что прислать по каждому кейсу

1. **Авто** — марка и модель (можно с годом): «VW Passat B6, 2012»
2. **Узел** — стартер или генератор
3. **Формат работы** — клиент приехал на машине (снимали у нас) или привёз/прислал снятый узел (важно для точности текста!)
4. **Симптом** — как клиент описал проблему (1–2 предложения, своими словами)
5. **Что оказалось** — реальная причина после разборки/диагностики
6. **Что сделали** — работы и запчасти
7. **Срок** — «2 часа» / «в день обращения» / «2 дня»
8. **Цена** — фактическая итоговая («90 BYN»)
8. **Фото 2–4 шт.** (см. требования ниже)

## Требования к фото

- **«До» обязательно**: разобранный узел, сгоревшая деталь, износ — это самое ценное фото
- **«После»**: собранный/отремонтированный узел или проверка на стенде
- Снимать **горизонтально**, при дневном свете или с подсветкой телефона
- Фон — верстак, без лишнего хлама
- **Без номеров авто и лиц клиентов** в кадре
- Не использовать чужие фото из интернета — только свои

## Как передать

**Простой путь:** прислать текст и фото в Telegram/WhatsApp — выложим сами.

**Самостоятельно (через GitHub в браузере):**
1. Открыть `src/content/cases/` → Add file → Create new file
2. Имя файла: `marka-model-uzel.md` (латиницей, через дефис)
3. Скопировать шаблон ниже, заполнить поля, Commit changes
4. Фото загрузить в `public/images/` тем же способом

## Шаблон файла кейса

```markdown
---
title: 'VW Passat B6: стартер щёлкал, но не крутил'
car: 'Volkswagen Passat B6, 2012'
unit: 'Стартер'
symptom: 'При повороте ключа — щелчок, дальше тишина. Аккумулятор заряжен.'
solution: 'Заменили втягивающее реле и щётки, зачистили коллектор, проверили на стенде.'
price: '90 BYN'
time: '2 часа'
date: 2026-08-03
before: /images/имя-фото-до.jpg
after: /images/имя-фото-после.jpg
---

Здесь 2–3 абзаца истории: как приехали, что нашли при разборке,
что удивило (если было), чем закончилось. Пишите как есть,
простым языком — это читают лучше всего.
```

## Важно

- Только **реальные** случаи и реальные цены. Кейс с честной ценой убеждает сильнее, чем «идеальный».
- Интересны не только удачные ремонты: кейс «узел оказался неремонтопригоден — честно сказали клиенту» тоже работает на доверие.
