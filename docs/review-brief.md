## 1. Бизнес-контекст

- **Бизнес:** автосервис «RSG Group», Минск. Узкая специализация: ремонт стартеров и генераторов (только легковые).
- **Клиенты:** автовладельцы Минска и окрестностей; дополнительно приём узлов Европочтой со всей Беларуси (доставка за счёт сервиса).
- **Текущие каналы:** сарафан + карточка Яндекс.Карт (рейтинг 4.9, 66 отзывов, 162 оценки). Старый сайт на Tilda давал ~0 обращений и плохо индексировался.
- **Целевые действия на сайте:** звонок (1 номер А1) + сообщения в Telegram/WhatsApp/Viber. Форм нет сознательно (некому обрабатывать).
- **Сезонность:** пик спроса октябрь–февраль. Дедлайн запуска — конец сентября 2026.
- **Реклама после запуска:** Google Ads $300/мес + Яндекс Директ $300/мес, вести будет владелец (новичок).
- **Конкуренты в топе (Минск):** starts.by (страницы услуг с ценами «от 29,90 BYN», легковые+грузовые), startergenerator.by (длинные экспертные тексты по неисправностям), stargen.by. У всех — устаревший дизайн, у части нет мобильной адаптации, блогов/кейсов нет.
- **Ограничения:** админки нет — контент правится владельцем через GitHub web-интерфейс с помощью нейросети; бюджет инфраструктуры $0.

## 2. Техническое решение

- **Стек:** Astro 7 (статическая генерация) + Tailwind CSS 4. Без JS-фреймворков — весь интерактив на ванильном JS в компонентах.
- **Хостинг (план):** Cloudflare Pages (бесплатный), автодеплой из GitHub. Домен сохраняется старый: remontstarterov.by (возрастной, была Tilda).
- **Контент:** единый файл данных `src/data/site.ts` (контакты, услуги, цены, FAQ, квиз, отзывы, калькулятор) + кейсы как Astro Content Collection (markdown с Zod-схемой).
- **Производительность:** чистый HTML, изображений мало (4 стока, локальные), шрифт Inter с Google Fonts, цель Lighthouse 90+.

### Структура проекта

```
src/
  data/site.ts          # весь контент: контакты, услуги, FAQ, квиз, отзывы, цены калькулятора
  content.config.ts     # схема коллекции кейсов (Zod)
  content/cases/*.md    # кейсы ремонтов (пока 2 шаблона)
  layouts/
    Base.astro          # <head>: мета, OG, canonical
    SiteLayout.astro    # шапка/футер/CTA-панель + Schema.org AutoRepair
  components/
    Header, Footer, StickyCta (липкая мобильная панель: звонок+мессенджеры)
    Calculator (вилки цен), Quiz (симптом→причина+цена+WhatsApp с готовым текстом)
    ReviewsCarousel (6 реальных отзывов с Яндекс Карт), Gallery, BeforeAfter (слайдер до/после)
    RouteButton (диплинк Яндекс Навигатора: Android intent://, iOS yandexnavi://)
    OpenStatus (живой «открыто/закрыто» по времени Минска), HomeContacts (встроенная Яндекс.Карта)
    Analytics (Яндекс.Метрика+GA4, цели по data-goal на звонки/мессенджеры/маршрут)
  pages/
    index.astro (главная), remont-starterov, remont-generatorov, diagnostika,
    dlya-regionov (Европочта), kontakty, keisy/ (список + [slug])
public/robots.txt, favicon.svg, images/ (4 стока, временные)
```

### Структура главной (порядок блоков)

Hero (оффер + звонок + маршрут + мессенджеры) → 4 преимущества → Услуги с ценами →
Калькулятор → Квиз «Что случилось?» → Галерея → До/после → 4 этапа работы →
Рейтинг 4.9 → Карусель отзывов → Блок Европочты → Карта+контакты → Финальный CTA.

## 3. SEO-меры (уже сделано)

- Семантическая структура URL: /remont-starterov/, /remont-generatorov/ (сохранены со старого сайта), /diagnostika/, /dlya-regionov/, /kontakty/, /keisy/
- Уникальные title/description/H1 под кластеры запросов на каждой странице

- robots.txt + sitemap.xml (@astrojs/sitemap), canonical
- Контент: таблицы цен (пока плейсхолдеры), симптомы, FAQ (вопросы из «люди также ищут»), квиз и калькулятор для поведенческих факторов
