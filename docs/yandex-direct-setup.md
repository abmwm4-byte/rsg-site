# Яндекс Директ для RSG Group — настройка ($300/мес)

**Аккаунт:** servis.rsggroup (Яндекс ID) · **Счётчик:** Метрика 62982700 (цели уже созданы)
**Бюджет:** ~960 BYN/мес (~32 BYN/день) · **Ведёт:** владелец сам

> Оплата в BYN, НДС 20% уже учтён в сумме платежа. Первое пополнение — минимум ~20 BYN, лучше сразу 300–500.

## Часть 0. Подготовка (5 минут)

1. direct.yandex.by → войти под servis.rsggroup → «Разместить рекламу»
2. Если спросит тип: **привязать Метрику** — в настройках кабинета: Счётчики Метрики → указать **62982700** (возможно, потребует подтверждение доступа к Метрике — подтверди)

## Часть 1. Кампания: «Мастер кампаний»

Выбирай **Мастер кампаний** (НЕ экспертный режим — для самостоятельного ведения он проще и эффективнее на конверсиях).

**Параметры:**

| Параметр | Значение |
|---|---|
| Цель кампании | **Конверсии в Метрике** |
| Счётчик | 62982700 |
| Целевые действия | `call`, `telegram`, `whatsapp`, `viber` (4 цели; `route` — вторично, можно добавить) |
| Гео | **Минск** (убрать всё остальное) |
| Расписание | Пн–Вс 09:00–19:00 |
| Недельный бюджет | **225 BYN** (~960/мес) |
| Стратегия | Оптимизация конверсий (авто) |

## Часть 6. Еженедельная рутина владельца (10 минут)

1. **Расход** за неделю (~225 BYN)
2. **Конверсии** по целям: звонки + мессенджеры — и цена каждой (норма: ≤ 50 BYN)
3. **Поисковые запросы** (Статистика → Поисковые запросы): мусор → в минус-слова
4. Первая неделя — НЕ менять настройки (обучение автостратегии)
5. CTR ниже 8% — писать мне, доработаем тексты
