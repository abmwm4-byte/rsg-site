## Известные ограничения (принятые решения)

- Клики по `tel:` ≠ реальные звонки: десктопные звонки не учитываются, случайные тапы учитываются. Если через 2–3 месяца захочется точности — подключить подменный номер (Яндекс.Телефония) для Директа
- FAQ-разметка не даст rich-сниппет в Google (с 2023 только для gov/health) — работает на Яндекс
- `aggregateRating` в Schema.org взят с Яндекс.Карт — Google может игнорировать; для Яндекса полезен
